API Reference.
Engineered with precision.

A production-grade, reverse-engineered LinkedIn Profile Extraction API supporting Authenticated Voyager REST/Dash APIs and Zero-Cookie Public JSON-LD fallback.

Architecture & Dual-Engine Routing

Enterprise-ready scraping infrastructure with automatic fallback and bot-bypass.

Voyager REST-li

Queries LinkedIn's internal graph API with TLS browser fingerprinting in ~250ms.

Zero-Cookie Mode

Automatic fallback parsing Schema.org JSON-LD & meta tags when cookies are absent.

LRU Memory Cache

High-efficiency TTL in-memory caching with jitter rate limiting to prevent throttling.

POST /api/v1/profile
application/json

Extracts full structured profile data from a JSON request body. Accepts any valid profile URL or vanity username.

Live Interactive Request Live Sandbox
200 OK -- ms -- 
// Response will appear here...
Example Request 
curl -X POST "http://localhost:8000/api/v1/profile" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.linkedin.com/in/username"}'
import requests

response = requests.post(
    "http://localhost:8000/api/v1/profile",
    json={"url": "https://www.linkedin.com/in/username"}
)
profile_data = response.json()
print(profile_data["data"]["full_name"])
const res = await fetch("http://localhost:8000/api/v1/profile", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ url: "https://www.linkedin.com/in/username" })
});
const { data } = await res.json();
console.log(data.full_name);

Structured Data Models

Strongly-typed Pydantic v2 schemas returned by extraction endpoints.

ProfileData Object
Root profile payload
Field Type Description
public_id string Vanity handle identifier (e.g. username).
full_name string Full display name of the member.
headline string | null Current role / tagline.
profile_picture_url string | null High-resolution vector avatar URL.
background_picture_url string | null Cover / header banner image URL.
experience Array<Position> Complete work history timeline with company logos.
education Array<Education> Degrees, schools, majors, and study dates.
skills Array<Skill> Extracted skills with endorsement counts.

HTTP Status Codes

Standard machine-readable error responses and diagnostic codes.

200 OK Success

Profile successfully extracted and returned with structured metadata.

400 Bad Request Invalid URL

Supplied URL or identifier could not be parsed into a valid LinkedIn vanity ID.

403 Bot Block Auth Wall (999)

Profile requires authentication. Configure cookies in .env to enable deep extraction.

404 Not Found Profile Not Found

LinkedIn profile handle does not exist or has been deleted.
